# ATEO-Conseils — Charte graphique minimaliste

Principe : une page claire, lisible, sans fioritures. Ergonomie type carte mentale : 1 centre, 4 branches, 1 contact.

## 1. Esprit
- Minimalisme administratif : blanc, texte, un seul accent.
- Lisibilité avant décoration. Pas d'animation, pas de slider, pas de stock photo.
- Une page unique + ancre contact. Ne pas s'étaler.
- Ton : factuel, sobre, institutionnel collectivités.

## 2. Couleurs — 4 max
- Fond : Blanc `#FFFFFF`
- Texte : Encre bleu-gris `#1A2332`
- Secondaire : Gris doux pour filets et fonds alternés `#F2F4F7` / bordure `#E2E6EB`
- Accent unique : Bleu Europe `#003399`
  - Usage : liens, pastille, soulignement titre, bouton contact.
  - Jaune Europe `#FFCC00` : interdit sauf mini-pastille 8px devant "FSE+ / FEDER" si besoin. Jamais en fond.

Règle : 90% blanc / gris, 10% bleu. Pas de dégradé, pas d'ombre portée, pas de transparence.

## 3. Typographie — 1 famille
- Famille : sans-serif système lisible type `Inter, Public Sans, Arial`. 2 graisses max : Regular 400 + Semi-bold 600.
- Échelle :
  - H1 : 28-32px, 1 seul par page : "Pierre Barneron — ATEO Conseils, fonds européens"
  - H2 : 20-22px pour les 4 branches
  - Texte : 16-17px, interligne 1.6, lignes 60-70 caractères max
  - Petit légal : 13-14px gris `#5B6572`
- Pas de majuscules intégrales, pas d'italique sauf mention légale formation.

## 4. Mise en page carte mentale
Desktop max 880px centré. Mobile 100% avec marges 20px.

Ordre vertical :
1. **Centre** — En-tête : Nom + baseline 1 ligne : "Consultant-formateur fonds européens depuis 1993 — FSE+, FEDER, aides d'État" + 2 boutons : [Me contacter] [07 / 09... / mail]
2. **Branche 1 Qui** — 3 lignes : 30 ans terrain, 15 ans État DGEFP, EI depuis 2008. Lien "Parcours".
3. **Branche 2 Ce que je fais** — 5 puces max issues du plan : systèmes gestion-contrôle, instruction / CSF, aides d'État / SIEG, formation intra, outils / guides.
4. **Branche 3 Pour qui** — 3 puces : autorités gestion / Régions, OI / Départements, bénéficiaires.
5. **Branche 4 Preuves** — 3 lignes : Corse 2026, Aude 2023, Deux-Sèvres 2021 + "Références complètes sur demande".
6. **Contact** — mail en clair cliquable, tél, adresse Peyrins / Lyon, SIREN 422673509, n° formation. Formulaire 3 champs : nom, email, message. Rien d'autre.

Séparateurs : 1px gris. Espacement généreux : 48px entre blocs, 16px interne. Pas de cartes à ombre, juste listes à puces avec filet gauche bleu 3px pour les branches.

## 5. Ergonomie
- Contraste AA minimum. Liens soulignés.
- Navigation : pas de menu. Ancres discrètes en haut : Qui / Missions / Contact.
- Clic-to-mail et clic-to-call obligatoires. Mail affiché en texte, pas en image.
- Formulaire : labels visibles, pas de placeholder seul, message confirmation simple.
- Temps chargement <1s : pas de font externe lourde, pas de JS sauf formulaire.
- Accessibilité : hiérarchie H1-H2 logique, focus visible bleu, site utilisable clavier.

## 6. Interdits
- Pas de carousel, pop-up, bandeau cookie décoratif, compteurs animés.
- Pas d'icônes 3D, pas d'emojis, pas de drapeaux en grand.
- Pas de jargon non expliqué : toujours "FSE+ (Fonds social européen)" à la première occurrence.
- Pas d'autres cabinets, pas d'immobilier homonyme. Uniquement ATEO / Barneron.
- Pas de gris clair sur blanc pour texte courant.

## 7. Éléments concrets à produire
- Logo texte seul : "ATEO Conseils" en semi-bold encre + pastille bleue 8px. Pas de nouveau sigle.
- Bouton unique : fond `#003399`, texte blanc, radius 6px, padding 12x20.
- Favicon : pastille bleue "A".

Validation : lisible en 10 secondes, contact trouvable en 2 clics, imprimable proprement en noir et blanc.
